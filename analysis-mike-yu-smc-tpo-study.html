一、审核范围与证据边界

核实日期为 2026-08-16。研究对象是 Mike Yu 聰明錢频道三套播放列表。多数视频没有公开可下载字幕，因此视频结论依据公开标题、章节、说明与可见案例，而不是完整逐字稿或连续成交审计。视频中的成功交易、资金账户通过或平台展示只能作为案例，不能证明长期净盈利。

二、SMC 基础 9 集

  1. 什么是订单流：用流动性与价格交付叙事理解市场，但不等于真实逐笔订单流。
  2. 流动性：前高前低、等高等低及止损聚集区是候选目标；“主力猎杀”不能仅凭图形确认。
  3. 市场结构：HH/HL、LH/LL、BOS、MSS/CHOCH；Swing 与突破确认必须机械定义。
  4. Order Block：位移前的候选订单块；范围、失效与回测规则主观性较高。
  5. Breaker：失效 OB 转为反向参考区；需避免事后选择最漂亮的区块。
  6. FVG：三根 K 线形成的失衡区；其存在不自动意味着价格必然回补或反转。
  7. PO3：Accumulation、Manipulation、Distribution 的叙事框架，Session 划分必须事前固定。
  8. 斐波那契：Premium/Discount 与回撤区；锚点若事后移动会产生选择偏差。
  9. ICT 2022：流动性扫荡 → MSS/位移 → FVG 首次回踩 → 对侧流动性目标。

基础课程最终可归纳为：高周期方向或流动性目标 → 扫一侧流动性 → 位移与 MSS/BOS → 首次回测 FVG/OB → 对侧流动性。它是一套价格行为语言，不是机构身份或正期望的证明。

三、SMC 实战 6 集

  1. 美股指数 1 分钟剥头皮交易。
  2. NASDAQ 剥头皮案例。
  3. S&P 500 短线交易。
  4. Topstep 资金账户与 TradingView 执行案例。
  5. 上涨行情中的短线交易。
  6. SMC 综合实战应用与课程公开。

实战内容增加高周期偏见、纽约时段、ES/NQ 关联、顺势与逆势分类、止损移动和目标调整。最适合机械验证的部分是：高周期同向 → 小周期扫逆向流动性 → MSS 与位移 → 首次回测 FVG。但 1m 剥头皮对点差、佣金、滑点、延迟与新闻极为敏感，公开视频只展示案例，缺少全部失败信号和连续净值。

四、TPO / Order Flow 10 集

  1. TPO 入门：统计价格在各区间出现的时间，寻找价值与市场接受。
  2. TPO 核心：POC、Value Area、VAH/VAL 与拍卖结构。
  3. Auction Rejection：尝试离开价值区后迅速返回。
  4. Auction Break：价格离开价值区；突破本身不保证延续。
  5. Auction Acceptance：市场在新区间持续交易并建立接受。
  6. VWAP：成交量加权平均成本；Session 与锚点必须预先冻结。
  7. 资金账户案例：属于个案与平台情境，不是长期盈利证据。
  8. 动态/Anchored VWAP：锚点事后移动会显著夸大解释力。
  9. CVD：累计主动买入减主动卖出；依赖交易所、市场类型、分类与重置规则。
  10. Heatmap：显示历史限价挂单；挂单可撤销，需区分 resting liquidity、成交、吸收与 spoofing。

五、从视频到可回测假设

  • 价值区突破：前一日 VAH/VAL/POC → 收盘确认离开价值区 → VWAP 同向 → 回测边界但不重新接受旧价值区。
  • 拍卖拒绝：突破失败并收回价值区 → 可选 CVD 吸收/背离和低周期 MSS → POC 或价值区另一侧。
  • SMC 顺势执行：已完成高周期方向 → 扫逆向流动性 → MSS → ATR 位移形成 FVG → 只做首次回踩。

六、SOL 回测共同口径

  • Bybit SOLUSDT 1m OHLCV/turnover，约覆盖 2023-01-01 至 2026-08-08。
  • 完成的 5m 信号，下一根 1m 开盘执行；高周期与 TPO 只向后对齐。
  • 单边手续费 5.5 bp、滑点 2 bp、Funding 压力每 8 小时 1 bp。
  • DEV 2023–2024、OOS 2025、Forward 2026 分开报告。
  • 保留每版代码、配置、信号、逐笔交易、净值和失败结论。

八、亏损诊断

  • V1 的 363 笔突破中，257 笔集中在 00:00 UTC，主要源于自然日切换后参考价值区突变，不一定是真实盘中突破。
  • 突破多头平均约 +13.37 bp，空头约 -30.19 bp；但事后删除空头会构成结果导向选择。
  • 拍卖拒绝的实际净盈亏接近 1:1，胜率仅 33.52%，远低于约 50.14% 的盈亏平衡要求。
  • Funding、数据缺口和明显未来泄漏不是主要根因；主要问题是信号边际薄、Session 不自然、交易频率与成本不匹配。

十三、完整研究结论

  1. SMC、TPO、VWAP、CVD 与 Heatmap 有助于描述市场，但概念不等于 alpha。
  2. 高周期方向确实影响结果，却不能自动创造优势。
  3. 单段 OOS 盈利不能覆盖 DEV 与 Forward 失败，不能据此挑选版本或品种。
  4. 当前 SMC + TPO V4 在 SOL、BTC、ETH 三个市场均停止，不进入实盘或继续调参。
最终决定

保留三套视频审核、V1–V4、亏损诊断、因果测试和 BTC/ETH 外部验证作为完整失败档案。未来只有预先登记真正不同的新假设，或取得真实逐笔成交、CVD、历史 Level 2/Heatmap 与新增未见数据时，才创建独立版本。
