FRM1级：C03 统计基础

前情回顾

一、参数估计

1、参数

定义 X 为随机变量，观察到 x_1, x_2，…, x_T 的序列。假设 x 的观测值来自正态分布：

x ∼ \Phi(\mu, \sigma)

一般地，还需要假设随机变量是独立同分布的。这里可以说，随机变量 X 服从以 \mu 为均值、 \sigma^2 为方差的正态分布。例如，正态分布意味着峰度系数为3，可以检验它是否等于3。如果不是，则必须拒绝正态分布的假设，必须寻找另一种更适合数据的分布。

2、参数估计量

均值 \mu = E(X) 可以由样本均值估计：

m = \hat{\mu} = \frac{1}{T} \sum_{i=1}^{T}{x_i}

样本均值是一个估计量(estimator)，这个样本的估计值是一个点估计(point estimate)。这里给所有观测值分配相同的权重 1/T ，由于独立同分布，它们都有相同的概率。然而，其他的估计也是可能的。只要权重之和为1，权重模式可以不同。一个好的估计量应该有以下特性：

  • 无偏(unbiased)：期望等于兴趣参数，E[m] =\mu 。否则，估计量是有偏的。
  • 有效(efficient)：它在所有可能的估计量中具有最小的标准差， V[m−\mu] 为最小值。

样本均值满足所有这些条件。在所有数据的线性组合中，一个无偏且有效的估计量被称为最佳线性无偏估计量(best linear unbiased estimator, BLUE)。

一个较弱的条件是估计量是一致(consistent)的。这意味着当样本容量 T 增加或渐近时，它收敛于真实参数。

方差 \sigma^2 = E[(X− \mu)^2] 可以由样本方差估计：

s^2 = \hat{\sigma}^2 = \frac{1}{T-1} \sum_{i=1}^{T}{(x_i - \hat{\mu})^2}

这里除以 T−1 而不是 T 。这是因为估计了一个未知参数（均值）的方差，所以自由度要减1。因此需要调整 s^2 ，以确保它的期望等于真值，或者它是无偏的。然而，在大多数情况下， T 很大的，所以这个调整是很小的。这些估价值取决于特定的样本，因此具有一些固有的可变性。样本均值的分布是：

m = \hat{\mu} ∼ N(\mu, \sigma^2/T)

如果总体分布是正态分布，这恰好描述了样本均值的分布。否则，中心极限定理表明该分布仅渐近有效（对于大样本）：

se(m) = \frac{\sigma}{\sqrt{T}}

即，在独立的情况下，样本均值的标准误是由总体波动性除以观测数 T 的平方根给出的。

样本方差 \hat{\sigma}^2 的分布为：

\frac{(T-1) \hat{\sigma}^2 }{\sigma^2} \sim \chi^2(T-1)

如果样本容量 T 足够大，卡方分布收敛为正态分布：

\hat{\sigma}^2 \sim N(\sigma^2, \sigma^4 \frac{2}{T-1})

采用同样的近似，样本标准差为正态分布，标准误差为：

se(\hat{\sigma}) = \frac{\sigma}{\sqrt{2T}}

可以利用这些信息进行假设检验。例如，想要检测 X 的一个常量趋势，这里的零假设是 \mu =0 。计算一个标准正态变量作为估计均值与标准误差的比值：

z = \frac{m-0}{\sigma / \sqrt{T}}

这是一个标准正态变量，不会期望观察到离0很远的值。需要确定测试的显著性水平，也是1减去置信度。通常，我们将 c 设为95%，这意味着 z_c 的双尾区间为 [-1.96,+1.96] 。显著性水平是5%。如果 z 的绝对值大于2，拒绝 m 来自均值为0的分布的假设。可以确信，真正的 \mu 不等于零。

若不知道真正的 \sigma ，而是使用估计的 s 。这个分布就变成了有 t 个自由度的学生 t 分布：

t = \frac{m-0}{s/\sqrt{T}}

截止值可查表。这个间隔的分位数是 t_c 。然而，对于较大的 T 值，这种分布接近正态分布。这些检验统计量可以转换为 置信区间。这些是包含真实参数的随机区间，具有固定的置信度：

c = P[m− z_c × se(m) ≤ \mu ≤ m+ z_c × se(m)]

例如，想要确定一个包含 \mu 的95%置信区间。如果 T 很大，我们可以用正态分布，乘子 z_c 是1.96。均值的置信区间是：

m± z_cse(m) = [m− 1.96 × se(m),m+ 1.96 × se(m)]

在这种情况下，置信区间是对称的，因为分布是正态的。更普遍地说，这个区间可能是不对称的，例如卡方分布是不对称的。

3、选择显著性水平

第1类错误拒绝正确的模型。第2类错误接受不正确的模型。对于给定的测试，增加显著性水平将减少第1类错误的概率，但增加第2类错误的概率。

因此，对于给定的测试方法，这两种错误之间存在权衡。显著性水平的选择应反映每个错误的代价。然而，测试方法至少应该设计得非常强大。这意味着，对于固定的第1类错误，产生第2类错误的概率应该尽可能低。

4、估计的精确度

当样本量增加时， \hat{\mu} 的标准误差以 1/ \sqrt{T} 的比例缩小。估计的精度随着观测数量的增加而增加。这一结果将证明有助于评估数值模拟(numerical simulations)产生的估计精度，在风险管理中广泛应用。数值模拟在固定数量的重复 T 次创建独立的随机变量，如果 T 太小，最终的估计将不精确测量。如果 T 非常大，估计是准确的。估计的精度以 1/ \sqrt{T} 的速度增加。

在独立的情况下，大多数统计量的标准差与观测次数 T 的平方根成反比，观测次数越多，估计越精确。

⭐ 例3.1 What does a hypothesis test at the 5% significance level mean?

  • a. P(not reject H0 | H0 is true) = 0.05
  • b. P(not reject H0 | H0 is false) = 0.05
  • c. P(reject H0 | H0 is true) = 0.05
  • d. P(reject H0 | H0 is false) = 0.05

解析：选 c 。显著性水平是提交第1类错误或拒绝正确模型的概率，即P(reject H0 | H0 is true)。相比之下，第2类错误为P(not reject H0 | H0 is false)。

⭐ 例3.2 When testing a hypothesis, which of the following statements is correct when the level of significance of the test is decreased?

  • a. The likelihood of rejecting the null hypothesis when it is true decreases.
  • b. The likelihood of making a type 1 error increases.
  • c. The null hypothesis is rejected more frequently, even when it is actually false.
  • d. The likelihood of making a type 2 error decreases.

解析：选 a 。显著性水平也是发生第1类错误的概率，或者当原假设为真时拒绝原假设的概率，这个概率在减小。这与答案b和c相反，这两个答案都是错误的。这就增加了犯第二类错误的可能性，即接受错误的假设，所以答案d是错误的。

⭐ 例3.3 A population has a known mean of 1,000. Suppose 1,600 samples are randomly drawn (with replacement) from this population. The mean of the observed samples is 998.7, and the standard deviation of the observed samples is 100. What is the standard error of the sample mean?

  • a. 0.025
  • b. 0.25
  • c. 2.5
  • d. 25

解析：选 c 。 \sigma / \sqrt{T} = 100/ (1,600)^0.5 = 100/40 = 2.5。

5、分布的假设检验

定义估计偏度为 \hat{\gamma} ，估计峰度为 \hat{\delta}。正态分布的真实值为 \gamma = 0 ， \delta = 3 。

Jarque-Bera (JB) 统计量测量了与期望值的偏差：

JB = T[\frac{\hat{\gamma}^2}{6} + \frac{(\hat{\delta}-3)^2}{24}]

在零假设下它有两个自由度的卡方分布。95%置信水平的截断点是5.99。如果JB统计量的观测值高于5.99，就拒绝观测值来自正态分布的假设。

二、回归分析

1、最小二乘法

线性回归表示为：

y_t = \alpha + \beta x_t + \epsilon_t

其中 y 为回归变数(regressand)， x 为回归量(regressor)， \epsilon 为误差项。

估计的回归为：

y_t = \hat{\alpha} + \hat{\beta} x_t + \hat{\epsilon}_t

其中估计误差 \hat{\epsilon} 为残差(residual)。

普通最小二乘(OLS)的假设包括：

  • 误差与变量 x 无关。
  • 误差的方差是常数。
  • 误差在不同的观测中是不相关的。
  • 误差是正态分布的。

两个随机变量 u 和 v 之间的独立性是一个强假设;这意味着协方差 Cov(u, v) 和相关性 \rho (u, v) 为零。否则，正态性假设会导致精确的统计结果。中心极限定理的条件随着 T 的增大而成立，这导致了类似的结果。

OLS通过最小化误差平方和 \Sigma \hat{\epsilon}_t^2 来提供系数的估计量。因此，估计量提供了最小的误差平方和。在模型假设下，高斯-马尔可夫(Gauss-Markov)定理表明OLS提供了最好的线性无偏估计量(BLUE)。估计量 \hat{\beta} 是无偏的，其期望是真实值 \beta 。“最好”表示OLS估计量是有效的，或者与其他估计量相比方差最小。当误差为正态时，OLS是最大似然估计量。然而，它对于更广的分布也有很好的性质。

OLS的估计量为：

\hat{\beta} = \frac{\sum_{t} (x_t - \bar{x}) (y_t - \bar{y})}{\sum_{t} (x_t - \bar{x})^2} ， \hat{\alpha} = \bar{y} - \hat{\beta} \bar{x}

当回归包含截距时，可以证明估计的残差必须通过构造平均为零：

\sum_{t=1}^{T}{\hat{\epsilon}} = 0

两个序列间的样本协方差可以写为：

\hat{\sigma}_{ij} = \frac{1}{T-1}\sum_{t=1}^{T}(x_{t,i} - \hat{\mu}_i)(x_{t,j} - \hat{\mu}_j)

为了解释 \beta ，可以取 y 和 x 之间的协方差：

Cov(y, x) = Cov(\alpha+ \beta x + \epsilon , x) = \beta Cov(x, x) = \beta V(x)

总体 \beta 可以表示为：

\beta(y,x) = \frac{Cov(y,x)}{V(x)} = \rho(y,x) \frac{\sigma(y)}{\sigma(x)}

然后就可以根据对 x 的观测建立对 y 的预测：

\hat{y}_t = E[y_t|x_t] = \hat{\alpha} +\hat{ \beta} x_t

这是一种非常方便的风险度量表示。这表明，当回归拟合良好时，变量 y 可以映射到变量 x 上，意味着误差项相对较小。

2、拟合质量

回归拟合(regression fit)可以通过检验残差的大小来评估：

\hat{\epsilon}_t = y_t - \hat{y_t} = y_t - \hat{\alpha} - \hat{\beta}x_t

可得估计方差为：

V(\hat{\epsilon}) = \frac{1}{T-2} \sum_{t=1}^{T} \hat{\epsilon}_t^2

除以 T−2 是因为估计量有两个未知量， \hat{\alpha} 和 \hat{\beta} 。拟合的质量可以用一种称为回归R平方的单位测度来评估，也称为决定系数(coefficient of determination)，定义为：

R^2 = 1 - \frac{SSE}{SSY} = 1 - \frac{\sum_{t}\hat{\epsilon}_t^2}{\sum_{t}(y_t - \bar{y})^2}

其中 SSE 是误差平方和(sum of squared errors)，而 SSY 是 y 在其均值附近的偏差平方和(sum of squared deviations)。如果回归包含常数，则 0 ≤ R^2 ≤ 1 。R^2 越大说明拟合越好。此时 R^2 也是相关系数的平方：

R^2 = \rho (y,x)^2

或者，我们可以通过分解方差来解释 R^2 ，推导可得：

V(y) = \beta^2V(x) + V(\epsilon) ，R^2 = \beta^2 \frac{V(x)}{V(y)}

评估拟合质量还包括检查是否满足OLS假设。例如，误差的分布应该具有恒定的方差：

V(\epsilon_t|x_t) = \sigma^2

也可以通过在 x_t 上绘制残差平方来检验。

3、假设检验

对于斜率参数， \hat{\beta} \sim N(\beta, V(\hat{\beta})) ，其方差为：

V(\hat{\beta}) = V(\hat{\epsilon}) \frac{1}{\sum_{t}(x_t - \bar{x})^2}

可以用来检验斜率系数是否显著不为零。相关检验统计量为：

t = \frac{\hat{\beta}}{\sigma(\hat{\beta})}

服从学生 t 分布。通常的做法是检查统计量的绝对值是否大于2。若大于2，拒绝 y 和 x 之间没有关系的假设，这相当于5%的双尾显著性水平。这也可以用来构造总体系数的置信区间。

4、自回归

自回归方程为：

y_t = \alpha + \beta_k y_{t-k} + \epsilon_t

如果 \beta 系数是显著的，那么该变量以前的变动可以用来预测未来的变动。在这里，系数 \beta_k 称为 k 阶自相关系数(autocorrelation coefficient)。实践中，大多数金融变量的斜率系数在统计上并没有显著的零差异。自相关性改变了跨界风险的正常模式。当不存在自相关时，风险随时间的平方根而增加。在正自相关的情况下，冲击的影响持续时间更长，风险增加的速度快于时间的平方根。

5、多元回归

多元回归的矩阵写法为：

y = X\beta + \epsilon

估计系数可以简写为：

\hat{\beta} = (X'X)^{-1}X' y

这里需要另一个假设：矩阵 X 必须是满秩的，一个变量不能是其他变量的线性组合。如果 X 不是满秩的，矩阵 X'X 就不是可逆的。这个假设排除了变量之间的完全相关性。然而，有时两个变量可以高度相关，这被描述为多重共线性(multicollinearity)。在这种情况下，回归输出是不稳定的。数据的微小变化可能导致估计值的巨大变化。系数会有非常高的标准误差。

系数的协方差矩阵为：

V(\hat{\beta} )=V(\hat{\epsilon}) (X'X)^{-1}

其中：

V(\hat{\epsilon}) = \frac{1}{T-N} \sum_{t=1}^{T} \hat{\epsilon}_t^2

令 \hat{\beta}_m 为组合系数， V_m(\hat{\beta} ) 为协方差矩阵。可以设定 F 统计量为：

F = \frac{\hat{\beta}_m' V_m(\hat{\beta} )^{-1} \hat{\beta}_m / m}{SSE / (T-N)}

这是具有 m 和 T - N 自由度的 F 分布。如果F值比表中的临界值大，将拒绝假设。

调整后R方(adjusted R-squared)为：

\bar{R}^2 = 1 - \frac{SSE / (T-N)}{SSY/ (T-1)} = 1- (1 - R^2) \frac{T-1}{T-N}

⭐ 例3.4 Consider the following linear regression model: Y = a +b X+ e. Suppose a = 0.05, b = 1.2, SD(Y) = 0.26, and SD(e) = 0.1. What is the correlation between X and Y?

  • a. 0.923
  • b. 0.852
  • c. 0.701
  • d. 0.462

解析：选 a 。思路是先求出V(x)，再求ρ。根据以下公式：

V(y) = \beta^2V(x) + V(\epsilon) ，\beta(y,x) = \rho(y,x) \frac{\sigma(y)}{\sigma(x)}

V(x) = [V(y) − V(ε)] / β^2 = 0.26^2 − 0.10^2) / 1.2^2 = 0.04，即 σ(x) = 0.2。因此，相关系数 ρ = σ(x) × β / σ(y) = 0.2 × 1.2 / 0.26 = 0.923。

⭐ 例3.5 Consider two stocks, A and B. Assume their annual returns are jointly normally distributed, the marginal distribution of each stock has mean 2% and standard deviation 10%, and the correlation is 0.9. What is the expected annual return of stock A if the annual return of stock B is 3%?

  • a. 2%
  • b. 2.9%
  • c. 4.7%
  • d. 1.1%

解析：选 b 。先构建A对B的回归模型 \hat{R}_A = R_F + \rho (\hat{R}_B - R_F) ，代入 R_F = 2%， \rho = 0.9， \hat{R}_B = 3%，有 \hat{R}_A = 2% + 0.9(3% − 2%) = 2.9%。

6、回归缺陷

有时，在 X 变量中有测量误差(measurement errors)，导致测量的 X 与 \epsilon 相关。这个所谓的变量误差(errors in the variables)问题导致了估计系数的向下偏差。

一个相关的问题是规范误差(specification error)。假设真实的模型有 N 个变量，但我们只使用子集 N_1 。如果省略的变量与包含的变量相关，估计的系数将有偏差。这是一个非常严重的问题，因为它很难识别。系数的偏差导致估计(estimation)问题。

另一类问题与系数的标准误差的潜在偏差有关。如果低估了标准误差，这些误差就会特别严重，从而在回归结果中产生错误的精确度，并可能导致错误的结论。OLS方法假设这些误差在观测中是独立的。这通常是金融时间序列的情况，但通常不是横断面设置。人们必须检查残差是否有系统的相关模式。即使是时间序列，误差中的自相关(autocorrelation)也会出现问题。标准误差中的偏差会导致推断(inference)的问题，因为人们可能会错误地得出一个系数在统计上是显著的。

当评估没有使用所有可用的信息时，效率(efficiency)就会出现问题。例如，残差可以在不同的观测值之间有不同的方差，此时存在异方差(heteroskedasticity)。这与同方差(homoskedasticity)的情况相反。当方差与自变量相关时，就会发生条件异方差。例如，较大的 X 值可能与高误差方差有关。这些问题可以通过残差的诊断检查来识别。如果存在异方差，可以构建更好的标准错误或尝试另一种规范。然而，这比估算或推断问题要小得多。低效的估计不一定会产生偏差。

回归可能具有多重共线性(multicollinearity)。当 X 变量高度相关时，就会出现这种情况，估计的 \beta 不可靠。然而，这个问题会在很大的标准误差中表现出来。可以通过丢弃一些与其他变量高度相关的变量来解决这个问题。

解析：选 d 。年龄和经验可能是高度相关的。当系数的标准误差较高时，多重共线性就会出现。

⭐ 例3.9 Which of the following statements regarding linear regression is false?

  • a. Heteroskedasticity occurs when the variance of residuals is not the same across all observations in the sample.
  • b. Unconditional heteroskedasticity leads to inefficient estimates, whereas conditional heteroskedasticity can lead to problems with both inference and estimation.
  • c. Serial correlation occurs when the residual terms are correlated with each other.
  • d. Multicollinearity occurs when a high correlation exists between or among two or more of the independent variables in a multiple regression.

解析：选 b 。a 项，当残差的方差不是常数时，存在异方差；b 项，异方差将导致低效的估计，但不会导致推论和估计方面的问题；c 项，当残差项相互关联时，就会出现序列相关，这是定义句；当两个或两个以上的自变量之间存在高度相关时，就会出现多重共线性，这是定义句。

⭐ 例3.10 Under what circumstances could the explanatory power of regression analysis be overstated?

  • a. The explanatory variables are not correlated with one another.
  • b. The variance of the error term decreases as the value of the dependent variable increases.
  • c. The error term is normally distributed.
  • d. An important explanatory variable is omitted that influences the explanatory variables included and the dependent variable.

解析：选 d 。如果真实回归包括第三个影响 y 和 x 的变量 z ，则误差项将不会有条件地独立于 x ，违反了OLS模型的假设。这人为地增加回归的解释能力，因为变量 x 可以解释 y 的更多变化，因为它与 z 相关。a 和 c 是正常情况；b 是条件异方差。
