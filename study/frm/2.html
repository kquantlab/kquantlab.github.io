FRM1级：C02 概率基础

前情回顾

一、描述随机变量

1、单变量分布函数

随机变量 X 的累积分布函数(cumulative distribution function)为：

F (x) = P(X ≤ x)

当变量 X 取离散值时：

F(x) = \sum_{x_j \leq x}^{}{f(x_j)}

其中， f(x) 称为频率函数(frequency function)或概率密度函数(probability density function)。当变量 X 为连续时，其分布为：

F (x) = \int_{-\infty}^{x}f(u)du

二者的关系为：

f (x) = \frac{dF(x)}{dx}

对于所有 u ，概率密度函数 f (u) 必须是正的。当 x 趋于无穷时，分布趋于1，表示为：

\int_{-\infty}^{\infty}f(u)du = 1

F (x) 测量的是 x 左边 F (x) 曲线下的面积。

2、矩

第一矩是均值，衡量样本的集中趋势或重心，由积分给出：

\mu = E(X) = \int_{-\infty}^{+\infty}xf(x)dx

该分布也可以用分位数来描述，分位数是截断点 x ，对应的概率为 c ：

F (x) = \int_{-\infty}^{x}f(u)du = c

因此，有 c 的概率这个随机变量会落在 x 以下，因为总概率加起来是1，所以有 p = 1 - c 的概率这个随机变量会落在 x 以上。将这个分位数定义为 Q(X, c) 。50%分位数称为中位数。

风险价值(VAR)可以被解释为一个截断点，例如，损失发生的概率不会大于p = 95%。如果 f (u) 为投资组合的损益分配，则定义VAR为：

F (x) = \int_{-\infty}^{x}f(u)du = 1-p

其中 p 是右尾概率， c 是通常的左尾概率。VAR可以定义为减去分位数本身，也可以定义为期望值与分位数之间的偏差，通常被报告为损失：

VAR(c) = E(X) − Q(X, c)

第二矩是方差：

\sigma^2 = V(X) = \int_{-\infty}^{+\infty}[x-E(X)]^2f(x)dx

标准差使用起来更方便，因为它与原始变量X有相同的单位：

SD(X) = \sigma = \sqrt{V(X)}

第三矩是偏度(skewness)，它描述了对对称性的偏离，定义为：

\gamma = \frac{1}{\sigma^3} \int_{-\infty}^{+\infty}[x-E(X)]^3f(x)dx

负偏度表示该分布具有较长的左尾，这表明观测到较大负值的概率较高。如果这代表一个投资组合的利润和损失的分配，这很危险。

第四矩是峰度(kurtosis)，它描述了一个分布的平坦度，或尾巴的宽度，定义为：

\delta = \frac{1}{\sigma^4} \int_{-\infty}^{+\infty}[x-E(X)]^4f(x)dx

尾部的大的观测值会有大的权重、产生大的峰度，被称为尖峰厚尾(leptokurtic, fat-tailed)。峰度为3表示正态分布。高峰度表明极端运动的可能性更高。峰度小于3的分布称为低峰(platykurtic)分布。

⭐ 例2.1 An analyst gathered the following information about the return distributions for two portfolios during the same time period:

Portfolio Skewness Kurtosis
A −1.6 1.9
B 0.8 3.2

The analyst states that the distribution for Portfolio A is more peaked than a normal distribution and that the distribution for Portfolio B has a long tail on the left side of the distribution. Which of the following is correct?

  • a. The analyst's assessment is correct.
  • b. The analyst's assessment is correct for Portfolio A and incorrect for Portfolio B.
  • c. The analyst's assessment is not correct for Portfolio A but is correct for Portfolio B.
  • d. The analyst's assessment is incorrect for both portfolios.

解析：选 d 。组合A的峰度小于3，因此比正态分布平坦。投资组合A为负偏态，左尾较长。故两句话均错误。

二、多元分布函数

1、联合分布

联合二元累积分布函数为：

F _{12}(x_1,x_2) = P(X_1 ≤ x_1,X_2 ≤ x_2)

若变量连续，则可以写做：

F _{12}(x_1,x_2) = \int_{-\infty}^{x_1} \int_{-\infty}^{x_2} f_{12}(u_1,u_2)du_1du_2

其中 f(u_1,u_2) 为联合密度(joint density)。联合分布和联合密度可以表示为乘积形式：

f _{12}(u_1,u_2) = f _{1}(u_1)×f _2(u_2)
F_{12}(x_1,x_2) = F _{1}(x_1)×F_2(x_2)

边际密度(marginal density)可以表示为：

f _{1}(x_1) = \int_{-\infty}^{+\infty} f_{12}(x_1,u_2)du_2

换做 x_2 也是类似的。条件密度(conditional density)可以表示为：

f_{12}(x_1|x_2) = \frac{f_{12}(x_1,x_2)}{f_2(x_2)}

这种关系也称为贝叶斯规则(Bayes' rule)。

2、协方差和相关性

协方差(covariance)的表达式为：

Cov(X_1, X_2) = \sigma_{12} = \int_{1}^{}\int_{2}^{}[x_1 - E(X_1)][x_2 - E(X_2)]f_{12}(x_1,x_2)dx_1dx_2

相关系数(correlation coefficient)介于-1至1之间，表达式为：

\rho (X_1, X_2) = \frac{Cov(X_1, X_2)}{\sigma_1 \sigma_2}

这个表达式也称为皮尔逊相关(Pearson correlation)。另一种度量方法是斯皮尔曼相关性(Spearman correlation)，它用变量的秩(Rank)代替变量的值。这种非参数测量对异常值不太敏感，因此当数据中可能存在错误时，它比通常的相关性更可靠。

如果变量是独立的，联合密度可以分解成：

Cov(X_1, X_2) = \{ \int_{1}[x_1 - E(X_1)]f_{1}(x_1)dx_1 \} \{ \int_{2}[x_2 - E(X_2)]f_{2}(x_2)dx_2 \} =0

在这种情况下，这两个变量是不相关的。因此，独立意味着零相关性。

⭐ 例2.2 Which one of the following statements about the correlation coefficient is false?

  • a. It always ranges from −1 to +1.
  • b. A correlation coefficient of zero means that two random variables are independent.
  • c. It is a measure of linear relationship between two random variables.
  • d. It can be calculated by scaling the covariance between two random variables.

解析：选 b 。相关性是线性关联的一种度量。独立意味着零相关性，但反过来不总是正确。

⭐ 例2.3 The joint probability distribution of random variables X and Y is given by f (x, y) = k× x × y for x = 1, 2, 3， y = 1, 2, 3 , and k is a positive constant. What is the probability that X+ Y will exceed 5?

  • a. 1/9
  • b. 1/4
  • c. 1/36
  • d. Cannot be determined

解析：选 b 。函数 x × y 的取值分布如下表所示：

x × y x = 1 x = 2 x = 3
y = 1 1 2 3
y = 2 2 4 6
y = 3 3 6 9

所有项的和是36。比例因子 k 必须使总概率为1。要使得 X+ Y >5，只能取 x=3,y=3 。因此概率为 p = 9/36 = 1/4 。

三、随机变量的函数

1、随机变量的线性变换

将原始随机变量乘以一个常数，并添加一个固定的量， Y = a + bX 。 Y 的期望是：

E(a + bX) = a + bE(X)

其方差为：

V(a + bX) = b^2V(X)

添加一个常数不会影响方差，因为计算涉及到变量与其均值之间的差。标准差为：

SD(a + bX) = b×SD(X)

2、随机变量的和

Y = X_1 + X_2 的期望为：

E(X_1 + X_2) = E(X_1) + E(X_2)

Y = X_1 + X_2 的方差为：

V(X_1 + X_2) = V(X_1) + V(X_2) + 2Cov(X_1, X_2)

求和的期望就是期望的总和。然而，和的方差只有在变量不相关的情况下才是方差的和。

3、随机变量的组合

考虑一些随机变量的线性组合。这可以是一个固定权重的投资组合，回报率是：

Y = \sum_{i=1}^{N}{w_iX_i}

其中 N 是资产的数量， X_i 是资产 i 的收益率， w_i 是权重。可以写成矩阵的形式：

Y = [w_1 \cdots w_N] \begin{bmatrix} X_{1} \\ \vdots \\ X_{N} \end{bmatrix} = w'X

其中， w' 表示转置后的权重向量（水平方向）， X 是包含单个资产回报的垂直向量。

投资组合的预期回报是：

E(Y) = \mu_p = \sum_{i=1}^{N}{w_i \mu_i}

其中，预期收益的加权平均值 \mu_i = E(X_i) 。方差为：

V(Y) = \sigma_p^2 = \sum_{i=1}^{N}{w_i^2 \sigma_i^2} + \sum_{i=1}^{N} \sum_{j=1, j \ne i}^{N} w_i w_j \sigma_{ij}
V(Y) = \sum_{i=1}^{N}{w_i^2 \sigma_i^2} +2 \sum_{i=1}^{N} \sum_{j=1, j < i}^{N} w_i w_j \sigma_{ij}

用矩阵表示法，方差可以写成：

\sigma_p^2 = [w_1 \cdots w_N] \begin{bmatrix} \sigma_{11} & \sigma_{12} & \sigma_{13} & \cdots & \sigma_{1N} \\ \vdots &&&&\vdots \\ \sigma_{N1} & \sigma_{N2} & \sigma_{N3} & \cdots & \sigma_{N}\end{bmatrix} \begin{bmatrix} w_{1} \\ \vdots \\ w_{N} \end{bmatrix}

将 \Sigma 定义为协方差矩阵，则投资组合收益率的方差可以更简洁地写成：

\sigma_p^2 = w' \Sigma w

以描述整个投资组合风险。

4、随机变量的乘积

Y = X_1 X_2 的期望为：

E(X_1 X_2) = E(X_1)E(X_2) + Cov(X_1, X_2)

当变量相互独立时，这就可以归结为两个均值的乘积。方差的计算比较复杂。有了独立性，它可以归结为：

V(X_1 X_2) = E(X_1)^2V(X_2) + V(X_1)E(X_2)^2 + V(X_1)V(X_2)

5、随机变量变换的分布

对于给定的 y ，可以找到 x 使 x = g^{-1} (y) 。可以写成：

P[Y ≤ y] = P[g(X) ≤ y] = P[X ≤ g^{−1}(y)] = F_X(g^{−1}(y))

其中， F(·) 为 x 的累积分布函数。假设关系为正。否则右边的项变成 1- F_X(g^{−1}(y)) 。

这种方法不容易扩展。对于一般的密度函数和变换，风险管理人员转向数值方法，特别是当随机变量的数量很大时。这就是为什么信用风险模型都是通过模拟来描述信用损失的分布的。

四、重要的分布函数

1、均匀分布

最简单的连续分布函数是均匀分布 U(a, b) ，密度函数为：

f(x) = \frac{1}{b-a} ， a ≤ x ≤ b

均匀分布的均值和方差为：

E(X) = \frac{a+b}{2} ， V(X) = \frac{(b-a)^2}{12}

均匀分布 U(0,1) 被广泛用作从任意分布 F (Y) 生成随机变量的起始分布。由于任何累积分布函数的范围都是从0到1，我们首先从 U(0,1) 画出 X ，然后计算 y = F^{-1} (x) 。随机变量 Y 将得到期望分布 f (Y) 。

⭐ 例2.6 The random variable Xwith density function f (x) = 1/(b− a) for a < x < b, and 0 otherwise, is said to have a uniform distribution over (a, b). Calculate its mean.

  • a. (a + b)/2
  • b. a − b/2
  • c. a + b/4
  • d. a − b/4

解析：选 a 。均匀分布的均值是分布的中心，也就是a和b的平均值。

2、正态分布

最重要的连续分布是正态分布，它充分地代表了许多随机过程。正态分布有一个钟形的形状，中心重量更大，尾部逐渐减小到零。股票价格的日回报率的分布与正态累计密度函数相似。正态分布只能由前两个矩来表征，密度函数的表达式如下：

f(x) = \frac{1}{\sqrt{2\pi \sigma^2}}exp[-\frac{1}{2\sigma^2}(x-\mu)^2]

其均值为 E[X] = \mu ，方差为 V[X] = \sigma^2 。正态分布可以表示为 N(\mu, \sigma^2)，因为函数可以由这两个参数完全指定，所以称为参数函数(parametric function)。使用标准正态变量(standard normal variable) \epsilon 通常更方便，其均值为 E(\epsilon ) = 0 ，方差为 V(\epsilon ) = \sigma(\epsilon ) = 1 。

正态分布函数是围绕均值对称。正态分布的偏度为0，峰度是3。尾部较粗的分布具有较大的峰度系数。右尾概率对应的值可以表示为：

\int_{-\alpha}^{\infty} f(\epsilon)d \epsilon = c

正态分布在金融中起着核心作用，它充分反映了许多金融变量的行为。例如，在Black-Scholes期权定价公式中，其中函数 N(·) 表示累积标准化正态分布函数。任何正态变量的分布都可以通过定义从标准正态变量的分布中重写：

X = \mu + \epsilon \sigma

可以得到其均值为 E[X] = \mu ，方差为 V[X] = \sigma^2 。

定义 X 在指定置信度 c 下的分位数为 Q(X, c) = \mu - \alpha \sigma ，可以计算VAR为：

VAR = E(X) − Q(X, c) =\mu - (\mu - \alpha \sigma) = \alpha \sigma

对于正态分布，投资组合的VAR是由投资组合标准差与一个反映置信度水平的标准正态偏差因子的乘积得到的，例如在95%水平上的1.645。

正态分布的一个重要性质是，它是少数几个在加法条件下稳定的分布之一。一个共同正态分布的随机变量的线性组合具有正态分布。联合正态变量的线性组合具有正态分布。

当有 N 个随机变量时，联合正态密度可以写成向量 x 、均值 \mu 和协方差矩阵 \Sigma 的函数：

f (x_1, . . . , x_N) = \frac{1}{(2\pi)^{N/2} |\Sigma|^{1/2}}exp[-\frac{1}{2}(x-\mu)'\Sigma^{-1}(x-\mu)]

⭐ 例2.7 Assume that a random variable follows a normal distribution with a mean of 80 and a standard deviation of 24. What percentage of this distribution is not between 32 and 116?

3、对数正态分布

如果随机变量 X 的对数 Y = ln(X) 是正态分布，则称其为对数正态分布(lognormal distribution)。这里定义 X = (P_1/P_0) 。因为对数函数中的参数 X 必须是正的，所以价格 P_1 不可能低于零。对数正态密度函数有如下表达式：

f(x) = \frac{1}{x\sqrt{2\pi \sigma^2}}exp[-\frac{1}{2\sigma^2}(ln(x)-\mu)^2] ， x > 0

其均值为：

E[X] = exp [ \mu + \frac{\sigma^2}{2}]

其方差为：

V[X] = exp[2\mu+ 2\sigma^2] − exp[2\mu+ \sigma^2]

选取的参数与正态变量的参数相对应：

E[Y] = E[ln(X)] = \mu ， V[Y] = V[ln(X)] = \sigma^2

反之，如果设 E[X] = exp[r] ，则相关正态变量的均值为 E[Y] = E[ln(X)] = r − \sigma^2/2 。

4、学生 t 分布

学生 t 分布描述了估计系数与标准误差的比率的分布，其密度函数为：

f(x) = \frac{\Gamma[(k+1)/2]}{\Gamma(k/2)} \frac{1}{\sqrt{k\pi}}\frac{1}{(1 + x^2/k)^{(k+1)/2}}

其中 \Gamma 函数定义为：

\Gamma(k) = \int_{0}^{\infty} x^{k-1} e^{-x} dx

随着 k 增加，这个函数收敛于正态概率密度函数。学生 t 分布是对称的，均值为零，方差为：

V[X] = \frac{k}{k-2} ， k >2

其峰度为：

\delta = 3 +\frac{6}{k-4} ， k >4

其尾部比正态分布更宽，这更好地代表典型的金融变量。对于股票收益来说， k 的典型估价值大约是4到6。也可以使用学生 t 来计算 VAR：

VAR = \alpha_k \sigma

乘数现在取决于自由度 k 。

另一种由正态分布导出的分布是卡方分布(chi-square distribution)，它可以看作是标准正态变量的独立平方之和：

x = \sum_{j=1}^{k}{z_j^2}

k 也称为自由度。其均值为 E[X] = k ，方差为 V[X] = 2k 。对于 k 足够大的值， \chi^2(k) 收敛于 N(k, 2k) 的正态分布。这个分布描述了样本方差。

最后，另一个相关的分布是F分布，它可以看作是独立的卡方变量除以它们的自由度的比率：

F (a, b) = \frac{\chi^2(a) / a}{\chi^2(b) / b}

这种分布出现在回归系数的联合检验中。

  • a. They have the same skewness and the same kurtosis.
  • b. The Student's t distribution has larger skewness and larger kurtosis.
  • c. The kurtosis of a Student's t distribution converges to that of the normal distribution as the number of degrees of freedom increases.
  • d. The normal distribution is a good approximation for the Student's t distribution when the number of degrees of freedom is small.

解析：选 c 。这两个分布具有相同的偏度为零，但学生 t 具有更高的峰度。随着自由度的增加，学生 t 分布收敛于正态分布。

5、二项分布

考虑一个随机变量可以取0到 n 之间的离散值。例如，去年超过VAR的次数，也称为异常(exceptions)的数量。因此，二项分布对于VAR模型的回溯检验起着重要的作用。

一个二项式变量可以被看作是 n 个独立的伯努利试验(Bernoulli trials)的结果，每个试验的结果是 y = 0 或 y = 1 。每个伯努利变量都有期望值 E[Y] = p 和方差 V[Y] = p(1- p) 。当离散密度函数为 f 时，定义随机变量为二项分布(binomial distribution)：

f(x) = \begin{pmatrix} n\\ x \end{pmatrix} p^x (1-p)^{n-x} ， x = 0, 1, . . . , n

其中，组合的表达式为：

\begin{pmatrix} n\\ x \end{pmatrix} = \frac{n!}{x!(n-x)!}

参数 p 在0和1之间。这个分布也表示 n 次重复实验中成功的总数，每次成功的概率为 p 。二项式变量的均值和方差为：

E[X] = pn ， V[X] = p(1 − p)n

一个相关的分布是负二项分布(negative binomial distribution)。这不是固定次数的试验，而是重复试验，直到出现固定次数的失败。其密度是：

f(x) = \begin{pmatrix} x+r-1\\ r-1 \end{pmatrix} p^x (1-p)^{r} ， x = 0, 1, . . .

这是伯努利过程第 r 次失败前成功次数的分布。其均值为：

E[X] = r \frac{p}{1-p}

其中， x 没有上限，和二项密度中的变量不同。

⭐ 例2.15 On a multiple-choice exam with four choices for each of six questions, what is the probability that a student gets fewer than two questions correct simply by guessing?

  • a. 0.46%
  • b. 23.73%
  • c. 35.60%
  • d. 53.39%

解析：选 d 。答对少于两个问题包括两种情况，计算如下：

  • 答对0题的概率 = 0.75^6 = 0.17798
  • 答对1题的概率 = 0.25×(0.75^5)×6 = 0.35596
  • 加起来得到 0.17798 + 0.35596 ≈ 0.5339

6、泊松分布

泊松分布是一种离散分布，通常用于描述在固定时间内发生的事件的数量，假设事件彼此独立。它被定义为：

f(x) = \frac{e^{-\lambda} \lambda^x}{x!} ，x = 0, 1, . . .

其中，\lambda 表示该期间平均到达率为正的数量。这种分布被广泛用于表示一年中业务损失发生的频率或次数。泊松分布的均值和方差相同：

E[X] = V[X] =\lambda

泊松分布是二项分布的极限情况，当 n 趋于无穷时， p 趋于0，但 np = \lambda 不变。当 \lambda 较大时，通过中心极限定理，泊松分布可以很好地用 \lambda 的均值和方差的正态分布来近似。如果到达的次数服从泊松分布，那么到达之间的时间周期服从以 1/\lambda 为均值的指数分布。后者的密度形式为 f (x) = \lambda e^{-\lambda x} ， x> 0 。例如，如果我们预计每年损失 \lambda= 12 ，则损失之间的平均时间间隔应该是一个月。

⭐ 例2.16 When can you use the normal distribution to approximate the Poisson distribution, assuming you have n independent trials, each with a probability of success of p?

  • a. When the mean of the Poisson distribution is very small
  • b. When the variance of the Poisson distribution is very small
  • c. When the number of observations is very large and the success rate is close to 1
  • d. When the number of observations is very large and the success rate is close to 0

解析：选 c 。当成功率 \lambda 非常高时，泊松方程的正态逼近会得到改进。因为这也是均值和方差，因此排除a和b是。当 np = \lambda 较大时，二项式密度可以很好地近似于泊松密度。

五、均值的分布

中心极限定理(central limit theorem, CLT)指出，随着观察数 n 的增加， n 个独立同分布(i.i.d)变量的均值收敛到一个正态分布。例如，假设违约总是相互独立的，当贷款数量增加到一个很大的值时，总信贷损失的分布收敛于一个正态分布。

定义 \bar{X} = \frac{1}{n}\sum_{i=1}^{n}{X_i} ，每个变量的均值为 \mu ，标准差为 \sigma ，可得：

\bar{X} \rightarrow N(\mu, \frac{\sigma^2}{n})

标准化后可得：

\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \rightarrow N(0,1)

正态分布是平均值的极限分布。考虑二项式变量，它是独立伯努利试验的和。当 n 很大时，可以使用CLT，用正态分布近似二项分布，可得：

z = \frac{x-pn}{\sqrt{p(1-p)n}} \rightarrow N(0,1)

这比二项分布更容易计算。

如果统计量落在95%的双尾置信区间之外，我们决定拒绝VAR正确的假设。对于标准化正态分布，这个区间是(−1.96，+1.96)。因此拒绝零假设，即观察到异常的真实概率仅为1%。换句话说，有太多的例外不能用坏运气来解释。VAR模型更有可能低估了风险。
